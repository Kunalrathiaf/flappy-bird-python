# 🐤 Flappy Bird Clone (Pygame)

A simple clone of the classic **Flappy Bird** game built using **Python** and **Pygame**. Fly your bird between pipes to earn points — don't crash!

---

## 🎮 Game Preview

![Gameplay Screenshot](./assets/gameplay.png)

---

## 🚀 Features

- Smooth bird animation with flap effect
- Randomized pipe generation
- Gravity and jump physics
- Collision detection and scoring
- Sound effects for flapping, hitting, and scoring
- Game over screen with high score display
- Retro pixel font styling
